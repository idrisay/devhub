## GitHub

Create a token at **Settings → Developer settings → Personal access tokens**. Classic tokens need `repo`; fine-grained tokens need read access to pull requests and checks.

The **Pull requests** panel has three groups: the pull request for your current branch (with its review state and check runs), your own open pull requests, and the ones awaiting your review. Each row shows whether it has conflicts, changes requested, failing checks or unresolved threads.

Both queues are scoped to the GitHub repositories open in your workspace. Review comments also appear as hints on the lines they were left on.
